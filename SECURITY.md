# Security

This is an early public release of a single-user local tool. It has not undergone an independent security audit. Keep the HTTP service on loopback and use a trusted computer.

Do not post keys, real receipts, databases or personal information in public reports. Please use GitHub private vulnerability reporting if enabled; otherwise contact the maintainer privately before disclosing sensitive details.

AI calls send selected data to the provider you configure. Local credentials are currently stored without application-level encryption.
